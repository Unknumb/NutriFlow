# DevSecOps Roadmap

## 1. Fundamentos y Conocimientos Previos

- **Lenguajes de Programación:** Ruby, Python, Rust, Go, JavaScript / Node.js
- **Scripting y SO:** Bash, PowerShell
- **Editores:** Vim, Nano, Emacs

## 2. Conceptos Base de Seguridad

- **Principios de Seguridad:** CIA Triad
- **Redes (Networking Basics):** Firewalls, VLANs, ACLs, Network Segmentation, DNS, HTTP, TLS
- **Gestión de Identidad (Identity Basics):** Authentication, Authorization, IAM, Least Privilege, Role Based Access
- **Criptografía:** Encryption (Symmetric, Asymmetric, Advanced Crypto, SHA 256, bcrypt, Hashing), PKI Design, Certificate Lifecycle

## 3. Seguridad en el Código y Aplicaciones

- **OWASP Top 10**
- **Secure Coding:**
  - SQL Injection Prevention
  - XSS Prevention
  - Input Validation Patterns
- **Secure API Design**

## 4. Gestión de Amenazas y Riesgos

- **Threat Modeling:** STRIDE, PASTA, Threat Modeling Workflows, Attack Surface Mapping
- **Vulnerability Scanning Tools:** Nessus, Nmap, OpenVAS, Qualys
- **Gestión de Riesgos:** Dependency Risk Management, SBOMS, Risk Quantification

## 5. Seguridad en Infraestructura y Despliegue

- **Cloud Security:** CSPM, Key Management Service
- **Container Security:** Docker, Kubernetes, Image Scanning
- **Pipeline:** Build Pipeline Hardening, Supply Chain Security
- **Secure Architecture:** Defense in Depth, Zero Trust Concepts, Multi Region Security, Secure Network Zoning

## 6. Monitoreo, Respuesta y Operaciones (Enterprise Operations)

- **Monitoreo y Logs:** SIEM, Log Analysis, Alert Types
- **Incident Response (IR):** IR Lifecycle, Forensics, Containment, Root Cause Analysis
- **Herramientas de Defensa:** IDS, IPS, DDoS Mitigation Strategy
- **Automatización de Seguridad:** SOAR Concepts, SOAR Automation, Automated Patching, EDR Strategy, Endpoint Detection

## 7. Gobernanza y Cumplimiento (Governance)

- **Frameworks:** SOC 2, ISO 27001, NIST
- **Auditoría:** Audit & Compliance Mapping
